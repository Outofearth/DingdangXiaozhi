# 小智语音音箱 · 使用说明

面向使用者的完整手册。装好后照着做一遍，能把它调成「说一句话就放歌」的状态。

- 只想聊天：看完第 1–4 章即可，不必配媒体源。
- 想放自己电脑里的歌：第 5 章。
- 想放网盘里的歌：第 6 章（需要在电脑上先装一个网关）。
- 遇到问题：直接跳第 11 章。

---

## 1. 它是什么

一个装在自己智能屏上的语音客户端。它做三件事：

1. 把你的话送上去，把回答播出来（语音对话）；
2. 听懂你在点播什么，在**本机 / 电脑共享 / 网盘 / 云端缓存**四个地方找出来并播放；
3. 把歌曲、视频、清单、聊天记录都显示在屏幕上，能用遥控点、也能用嘴说。

它不能：替代厂商的全部技能、脱离网络聊天、播放受版权保护且你没有的文件。

### 适用设备

| 项 | 要求 |
|---|---|
| Android | 7.0 及以上（`minSdk 23`） |
| CPU | ARM（armeabi-v7a / arm64-v8a 均可） |
| 屏幕 | 横向；已适配 1280×800 |
| 实测机型 | 腾讯叮当智能屏（MT8167 / Android 8.1） |

> 其他 Android 设备也能装（手机/平板有自适应版本），但悬浮入口、横屏布局、物理按键这些是按音箱调过的。

## 2. 安装

```bash
adb install -r xiaozhi-speaker.apk
```

装好后桌面上会出现「小智语音」。也可以直接在设备文件管理器里点 APK 安装。

如果没有 adb，可先在设备上打开「开发者选项 → USB 调试」，或用同一局域网的无线调试。

---

## 3. 首次启动

### 3.1 授予权限

首次打开会依次申请三项权限，都必须允许：

- **麦克风**：不给她就听不到你说话
- **存储**：读本地音乐、写缓存与聊天记录
- **相机**：拍照问答（不给也能用其他功能）

### 3.2 绑定设备

1. 启动后屏幕中间会显示一个 **6 位验证码**。
2. 用手机或电脑打开 <https://xiaozhi.me>，登录后进入「添加设备 → 输入验证码」。
3. 填完等几秒，App 会自己切换到「就绪」，屏幕上出现「麦克风 监听中」。

绑定只需要做一次。绑定关系保存在设备本地，重装 App 会丢（见 11.4）。

### 3.3 开始说话

按住右下角绿色圆钮说话，**松开**即发送。听到「叮」表示已开始录音。

## 4. 主界面

```
┌────────────────────────────────────────────┬──────────────┐
│ 状态栏（就绪 / 正在执行 …）   连续对话 相机 记录 设置 │              │
├────────────────────────────────────────────┤   麦克风状态  │
│                                            │              │
│   聊天流：你说的话（右侧绿气泡）            │   ● 按住说话  │
│           它说的话、清单、提示（左侧）      │              │
│                                            │  按住说话     │
│                                            │  点上方麦克风 │
│  ┌──────────────────────────────────────┐  │  可关闭收音   │
│  │ ▶ 正在播放：共享文件夹 · 某首歌       │  │              │
│  │   00:31 ──────●───────── 04:12       │  │              │
│  └──────────────────────────────────────┘  │              │
└────────────────────────────────────────────┴──────────────┘
```

- **状态栏**：显示连接状态。「就绪」= 可以说话；「正在执行 xxx」= 正在处理（比如在列清单）。
- **聊天流**：最新消息在最下面。清单、播放提示、进度都插在这里。
- **正在播放卡片**：贴在聊天流最下方，显示来源、歌名、进度。**点进度条可以拖**。
- **右上角四个入口**：连续对话开关、拍照、聊天记录、设置。
- **麦克风**：点一下可临时关掉收音（不想被听到时用），再点恢复。

## 5. 播放源

四种来源会在同一份清单里出现，按来源分组、序号全局连续。

### 5.1 本机文件

把音乐放进设备的 `Music/xiaozhi` 目录（或直接放 `Music`），文件管理器拷进去、或用脚本推送：

```bash
bash tools/push-music.sh ./我的歌单
```

支持 mp3 / flac / wav / m4a / aac / ogg / wma 等常见格式。

### 5.2 电脑共享文件夹（SMB）

让音箱直接读 Windows/Mac 上的共享目录，**不用拷文件**。

**电脑端**（Windows）：

1. 右键音乐文件夹 → 属性 → 共享 → 高级共享 → 勾选「共享此文件夹」。
2. 权限里给「Everyone」或「Guest」读权限。
3. 如果音箱连不上、提示需要凭据，用管理员身份运行 `tools/enable-smb-guest.bat`（它只放开局域网匿名读，不改其他设置）。

**音箱端**：设置 → 共享文件夹，填三项后点「测试连接」：

| 字段 | 填什么 | 例子 |
|---|---|---|
| 地址 | 电脑的局域网 IP 或主机名 | `192.168.1.50` 或 `DESKTOP-ABC` |
| 共享名 | 共享时起的名字 | `Music` |
| 账号 / 密码 | 匿名共享留空 | 留空 |

提示「连接成功，找到 N 个文件」就通了。

> **为什么是「边下边播」**：局域网每次读共享盘都是一次往返，音频播放器只要几 KB，往返一多就卡。
> 所以 App 会在后台顺序预取到本地，播放器读本地文件，跳到未下载区域时再单独连一次。
> 表现是「点下去 1–2 秒开始出声，之后一直流畅」。

### 5.3 网络盘（需要 PC 网关）

App 不直接对接各家网盘，而是通过电脑上的 **OpenList** 网关访问（详见第 6 章）。
配好之后，网盘里的音乐/视频和共享文件夹一样用：说名字、说序号都能放。

### 5.4 云端缓存

云端唱过的歌会整首存到设备上。第二次点同一首歌直接播，不再缓冲。
占用算在「存储与缓存 → 共享文件夹下载缓存」里，可随时清。

## 6. 网络盘网关（进阶）

> 只在想放网盘音乐时才需要。整条链路是：
> **音箱 → 局域网 HTTP → 电脑上的 OpenList → 你的网盘**

### 6.1 在电脑上装 OpenList

1. 从 <https://github.com/OpenListTeam/OpenList/releases> 下载对应系统的版本，解压到任意目录。
2. 启动（首次会生成管理员账号密码，注意看控制台输出）：
   ```bash
   ./openlist server --data ./data
   ```
   Windows 上双击 `openlist.exe` 也可以。
3. 浏览器打开 `http://127.0.0.1:5244`，用生成的管理员账号登录。

> 电脑防火墙要放行 5244 端口，否则音箱连不上。

### 6.2 挂载你的网盘

后台管理 → 存储 → 添加：

- **驱动**：选你的网盘（夸克 / 阿里 / 百度 / 115 / OneDrive …）
- **挂载路径**：比如 `/quark`，这就是以后在音箱上看到的根目录
- **根文件夹 ID / 路径**：填你想暴露给音箱的那一层（建议只挂音乐目录，不要挂整个网盘）
- 保存后回到首页，能在文件列表里看到你的网盘内容就对了

### 6.3 建一个只读账号给音箱

后台 → 用户 → 添加：

- 用户名随意，密码设一个
- **权限选「只读」**（只能看和下载，不能改名、删除、上传）

用只读账号，即使设备丢了也不会被人改你的网盘。

### 6.4 在音箱上填地址

设置 → 网络盘：

| 字段 | 填什么 |
|---|---|
| 网关地址 | `http://<电脑局域网IP>:5244` |
| 根目录 | 你挂载时起的路径，如 `/quark` |
| 用户名 / 密码 | 上面建的只读账号 |

点「测试连接」→ 出现绿色「连接成功，这里有 N 个文件夹」即通。
再点「刷新状态 / 看目录树」，会列出整个网盘的目录结构（这份树是从本地索引拼的，不联网）。

### 6.5 关于索引

App 会在后台慢慢把整个网盘的文件名扫一遍（一层层推进，扫完就存盘，下次接着扫）。
索引用来支持「说个名字直接放」。扫描过程中：

- 已经扫到的歌能按名字点播，没扫到的只能进目录按序号放；
- 设置页会显示「索引 N 条 / 已列 M 个文件夹」，扫完会显示「已扫完」。

网盘里新增的文件，半小时后会自动重新扫到。

## 7. 视频

说「播放 xxx（视频）」或从清单里选视频，会自动切到全屏视频页：

- 画面 + 进度条 + 字幕层（云端回答会以字幕显示，不打断画面）
- 视频页里点麦克风可以说话，系统会自动暂停画面让你说，说完接着放
- 语音控制：「暂停」「继续」「快进到十分钟」「退出」「下一集」
- 左上角「退出」回到聊天界面

网盘/共享盘上的视频同样是边下边播：刚开始会转几秒圈，之后就能拖动。

---

## 8. 音量

三种方式都行：

- **说**：「大声点」「小一点」「音量调到 50%」「静音」
- **设置页**：设置 → 音量，滑到想要的档位
- **机身按键**（如果设备有）

设备音量是 0–15 档（不是百分比）。说「50%」时 App 会换算成第 8 档，并把实际档位回显给你（屏幕上显示「53%（8/15 档）」这类文字）。

设置页有个「启动时自动应用音量」：打开则每次启动都用设定值覆盖系统音量；关掉则保留你上次在设备上手动调的。

---

## 9. 聊天记录

点右上角「记录」进入管理页：

- 按「今天 / 近 7 天 / 近 30 天 / 全部」筛选
- 长按单条可复制、删除
- 右上角「多选」批量删除；「导出」把当前筛选结果写成 TXT
- 上限 500 条，超出后自动丢最旧的

导出的 TXT 在设备的 `Android/data/com.altc.xiaozhi/files/exports/` 下，可用 `tools/cache.sh exports` 清理。

### 多设备同步

两台设备装同一个 App、绑定同一个账号、连同一个局域网时，会自动发现彼此并把聊天记录互相补齐（P2P，不经过服务端）。设置页里可以开关。

## 10. 设置页逐项

| 分组 | 项目 | 说明 |
|---|---|---|
| 连接 | 设备身份（device-id） | 就是绑定用的身份。改动它会等于换一台设备，**已绑定状态下不要动** |
| 连接 | 随机新身份 | 生成一个新的 device-id 填进输入框，需自行点保存才生效 |
| 连接 | 服务器地址 / Token | 一般不用改；用自建服务端时才改 |
| 连接 | 控制台 → | 看当前绑定状态与连接地址（Token 只显示前 6 位） |
| 语音 | 连续对话 | 开启后说完不用再按键，停顿自动提交 |
| 语音 | 摄像头 | 关掉后拍照功能整体停用 |
| 共享文件夹 | 地址 / 共享名 / 账号 / 测试连接 | 见 5.2 |
| 网络盘 | 网关地址 / 根目录 / 只读账号 / 测试连接 / 看目录树 | 见第 6 章 |
| 音量 | 档位、启动时自动应用 | 见第 8 章 |
| 播放 | 播完行为 | 续播下一个 / 重播当前 / 放完就停 |
| 存储与缓存 | 云端曲库、整包缓存、下载残片 | 见第 12 章 |
| 外观 | 列表/卡片、字号 | 适应不同观看距离 |
| 悬浮入口 | 待机时浮出一个按钮 | 需要「显示在其他应用上层」权限 |

## 11. 常见问题

### 11.1 说话没反应

1. 看右上角状态：不是「就绪」说明还没连上。
2. 检查麦克风图标是否被关掉（点一下恢复）。
3. 看网络：设备能不能上网、DNS 是否正常。
4. 退出重进 App；仍不行就重启设备。

### 11.2 清单列出来了，但说「播放第 3 个」没反应

清单有 3 分钟有效期，超过就作废（内容可能已经变了）。重新问一次再点播即可。
另外「第 3 个」里的序号必须是**屏幕上显示的序号**，不是某一段的第一个。

### 11.3 共享文件夹连不上

- 电脑和音箱必须在**同一个局域网**（不同网段、访客 Wi-Fi 都不行）
- 电脑防火墙放行「文件和打印机共享」
- Windows 需要允许 SMB1/SMB2；用 `tools/enable-smb-guest.bat` 可一次性搞定匿名读
- 地址尽量用 IP，不要用带空格或中文的计算机名

### 11.4 重装后绑定丢了

device-id 是随机的、存在 App 私有目录里，卸载会一起删掉。
重装前到设置页把「设备身份」抄下来；重装后填回原值，重启即可恢复绑定，不用重新输验证码。

### 11.5 播放时卡顿/断续

- 共享盘/网盘卡：多半是 Wi-Fi 带宽不够或电脑在忙。先确认电脑端能正常播同一首歌。
- 本机文件也卡：检查存储空间是否已满（低于 200 MB 时会频繁清理缓存）。
- 视频卡：视频码率高时（1080p 以上）局域网带宽可能不够，建议放本地。

### 11.6 网盘显示「连不上网关」

- 电脑上的 OpenList 是否在运行（浏览器打开 `http://<IP>:5244` 试试）
- 电脑 IP 变了（DHCP）——在路由器里给它设固定 IP 更稳
- 账号密码错、或账号不是只读/权限不对

### 11.7 屏幕上看不清字

设置 → 外观 → 字号，调到适合观看距离。

## 12. 缓存与空间

「存储与缓存」里有三类，各自独立：

| 类型 | 是什么 | 单次清理影响 |
|---|---|---|
| 云端曲库 | 云端唱过的歌整首存的 PCM | 下次听同一只要重新从云端唱一遍 |
| 整包缓存 | 共享盘 + 网盘下完的完整文件（二者共用 600 MB 上限，满了自动淘汰最久未用的） | 下次点播要重新下载 |
| 下载残片 | 边下边播中断留下的半成品 | 无影响，本来就该清 |

另外「缓存明细 → 查看」会按**大小从大到小**列出所有缓存文件，可以勾选着删——
想腾空间时清掉那几个几百兆的视频就够了，常听的歌留着。

标着「正在用」的那份不会被删（正在播的东西不能被拆掉）。

## 13. 排障信息

设置 → 控制台能看到：

- device-id / client-id / WebSocket 地址 / Token（前 6 位）
- 绑定状态、最近一次 OTA 时间
- 连续对话 / 摄像头 / 麦克风 / 照片留存的开关状态

设备上还留有一份运行日志（`Android/data/com.altc.xiaozhi/files/status.txt`），
如果遇到奇怪问题，把这个文件拉出来能看到每一步发生了什么：

```bash
adb shell cat /sdcard/Android/data/com.altc.xiaozhi/files/status.txt | tail -50
```
